
# CARA DAPAT APK DALAM 3 MENIT - TANPA ANDROID STUDIO

## Langkah 1: Upload ke GitHub
1. Buka github.com -> New Repository -> nama: perpusku
2. Upload semua file dari ZIP ini (drag & drop)

## Langkah 2: Auto Build APK
1. Setelah upload, buka tab "Actions" di GitHub
2. Kamu akan lihat workflow "Build APK" sedang jalan (kuning)
3. Tunggu 3-5 menit sampai hijau
4. Klik workflow -> scroll bawah -> ada "Artifacts" -> Download "PerpusKu-APK"
5. Di dalamnya ada app-release.apk - tinggal install di HP!

APK siap install.
